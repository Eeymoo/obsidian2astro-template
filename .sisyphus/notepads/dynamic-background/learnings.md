# DotBackground 组件实现笔记

## 2026-02-27

### Astro 客户端脚本模式
- Astro 组件内 `<script>` 标签中的代码会在客户端自动执行
- 可以直接 `import` 外部 TypeScript 模块
- 使用 `astro:before-swap` 事件处理页面切换时的清理

### 移动端检测
- 使用 `window.matchMedia('(pointer: fine)').matches` 检测精确指针设备
- 相比 `navigator.maxTouchPoints` 更准确反映设备交互能力

### Tailwind z-index 映射
- `-z-10` 等同于 `z-index: -10`
- 用于将背景元素置于内容之下

### 颜色对比度与主题适配
- 动态背景点阵需要足够微妙，以免分散对内容的注意力，但又要足够可见以提供良好的视觉效果。
- 在亮色模式（白色背景）下，使用 `slate-200` (`#e2e8f0`) 比 `slate-300` (`#cbd5e1`) 提供更好的微妙对比度，这与设计系统中的主要边框颜色一致。
- 在暗色模式（`slate-950` 背景）下，使用 `slate-700` (`#334155`) 比 `slate-600` (`#475569`) 提供更好的微妙对比度，这也与暗色模式设计系统中的主要边框颜色一致。
- 使用设计系统的边框颜色作为背景装饰，可确保整个应用程序的视觉一致性。
